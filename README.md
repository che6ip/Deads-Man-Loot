# Dead's Man Loot

Добыча с мёртвых существ в стиле WoW для **Foundry VTT**.

Базовый модуль содержит всю механику лута: окно добычи, бросок шансов при смерти, перенос
предметов, мешочки монет и проценты выпадения. Системно-зависимые значения передают адаптеры.

> **Важно:** сам по себе базовый модуль не работает. Нужен адаптер под вашу систему:
> **deads-man-loot-pf2e** для Pathfinder 2e или **deads-man-loot-dnd5e** для D&D 5e.

## Возможности

- Двойной клик по мёртвому токену открывает окно добычи.
- У каждого предмета можно задать шанс выпадения от 0 до 100%.
- Бросок добычи выполняется автоматически при смерти существа.
- В окне показываются только предметы, прошедшие бросок; название окрашено по редкости.
- Кнопка **«Взять»** переносит предмет персонажу игрока.
- ПКМ по предмету открывает его карточку.
- Мешочки монет: формулы в описании предмета автоматически начисляют монеты при использовании.
- Инвентарь НПС показывает шанс выпадения предметов — только для Мастера.
- Игроки без прав на труп работают через Мастера: получают список, переносят предметы и
  открывают карточки.

## Установка

1. Скопируйте папку `deads-man-loot` в каталог модулей Foundry: `Data/modules/deads-man-loot`.
2. Установите и включите адаптер под вашу систему:
   - `deads-man-loot-pf2e` для Pathfinder 2e;
   - `deads-man-loot-dnd5e` для D&D 5e.
3. Включите оба модуля в настройках мира (**Manage Modules**).
4. Обновите сцену клавишей **F5**.

Для игры нужен активный Мастер: он выполняет броски добычи и обслуживает запросы игроков.

## Как пользоваться

1. Откройте лист предмета и задайте **шанс выпадения** (способ зависит от адаптера системы).
2. Доведите существо до 0 хитов или повесьте статус «Мёртв»/«Кровоточит».
3. Дважды кликните по трупу на сцене — откроется окно добычи.
4. Нажмите **«Взять»** у нужного предмета: он перейдёт вашему персонажу.
5. ПКМ по предмету в окне открывает его карточку.
6. Закройте окно как обычно — добыча останется в трупе.

| Действие | Результат |
| --- | --- |
| Двойной клик по мёртвому токену | Открыть окно добычи |
| **«Взять»** у предмета | Перенести предмет персонажу игрока |
| ПКМ по предмету | Открыть карточку предмета |
| Закрыть окно | Ничего не переносится, список сохраняется |
| Оживить существо | Добыча сбрасывается, временные права снимаются |

### Шанс выпадения

- По умолчанию предмет без настроенного шанса выпадает всегда (**100%**).
- **0%** — предмет не появляется в добыче, **100%** — появляется всегда.
- Если изменить шанс уже после смерти, пересчитываются только затронутые предметы. Уже выпавшая
  добыча не перебрасывается.
- Настраивать шанс может только Мастер.

### Мешочки монет

Предмет-мешочек (обычно расходуемый) может содержать формулы монет в описании:

```text
[[/r 2d6]]{gp}
[[/r 1d8]]{sp}
```

При использовании или удалении такого предмета модуль тайно бросает формулу, начисляет монеты
персонажу и отправляет отчёт Мастеру в чат. Поддерживаются обозначения `cp`, `sp`, `gp`, `ep`, `pp`
и их русские названия.

## Настройки

Настройки мира, отображение шанса видит только Мастер.

| Настройка | По умолчанию | Описание |
| --- | --- | --- |
| Отображение шанса выпадения в инвентаре НПС | в иконке предмета | Варианты: в скобках после названия, справа-снизу в иконке, отключить |
| Цвет цифры шанса выпадения | `#000000` | Цвет текста процента |
| Цвет подложки шанса выпадения | `#FFFFFF` | Цвет фона под процентом |
| Прозрачность подложки шанса | 75 | От 0 (невидима) до 100 (непрозрачна) |
| Размер надписи шанса выпадения | 10 | Размер шрифта в пикселях, от 6 до 24 |

## Совместимость

- Foundry VTT **13+** (проверено на сборке 14.369).
- Требуется системный адаптер: **Pathfinder 2e** или **D&D 5e**.
- Для игроков нужен активный Мастер.
- Интерфейс модуля на русском языке.
